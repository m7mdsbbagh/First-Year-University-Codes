# 🧮 Smart Java Calculator

> A lightweight, interactive console calculator built with Java. Designed to practice and showcase Object-Oriented Programming (OOP) concepts.

### ⚙️ Features
- **Operations:** Supports addition `+`, subtraction `-`, multiplication `*`, and division `/`.
- **Safe Execution:** Built-in error handling to prevent application crashes (e.g., division by zero).
- **Interactive UI:** Dynamic user input via the console using the `Scanner` class.

### 📂 Structure
- `Calculator.java` : The core logic engine handling mathematical operations.
- `Main.java` : The application entry point managing inputs and outputs.

### 🚀 Quick Start
1. Run the `Main.java` file in your preferred IDE.
2. Follow the on-screen prompts to input numbers and select an operator.
