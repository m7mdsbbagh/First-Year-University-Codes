# 🎓 Student Management System (Java)

Welcome to my first professional Java project! This is a simple yet powerful system built to manage student records with a focus on **Clean Code** and **OOP** principles. ✨

## 🚀 Key Features
* **🔒 Encapsulation:** Using private fields to protect data.
* **🛠️ Modular Design:** Clean functions for initialization and display.
* **📊 Smart Formatting:** Professional table output using `printf`.
* **🛡️ Data Integrity:** Final IDs to prevent accidental changes.
